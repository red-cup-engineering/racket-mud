# Releases

## v0.1.0

[Source revision e5a3bcd752a5](https://github.com/red-cup-engineering/racket-mud/tree/e5a3bcd752a5da2a484629cf9edf9319ca8e0875)

Racket-MUD is revived as an immutable, message-driven MUD engine.

This release includes the world-neutral mudlib, deterministic message scheduling, account and login adapters, a bounded TCP line server, Scribble documentation, and 40 tests. It begins a new 0.x API and is not source-compatible with the historical engine generations.

The repository history preserves the recovered legacy engine, snapshot, application-subtree, and GitLab wiki lineages.
